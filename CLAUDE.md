# Служба механиков (meh.techno-res.ru)

Полные заметки по проекту — в файле ниже, он подключается автоматически:

@Механизация.md

## Где что лежит

- Локальная копия сайта: `public_html/` в этой папке
- На сервере: `~/meh/public_html` (Timeweb, аккаунт `c73065`) — **не** `~/public_html`,
  в аккаунте есть и другие проекты: `new`, `msk`, `msk-new`, `stage_ts`
- Выкладка только копированием файлов: сборки нет, composer/node на хостинге недоступны

## Главные правила при правках

- Статусы задач — только через справочник `task_statuses` и хелперы из
  `includes/functions.php`. Никаких `status = 'verified'` или `IN ('new',...)` в коде
- Смена статуса — исключительно через `change_task_status()`
- Вывод через `e()`, запросы только подготовленные, формы — `csrf_field()` / `csrf_verify()`
- Новые css/js подключать с `?v=filemtime(...)`, иначе браузеры держат старое сутками
- Интерфейс и комментарии на русском
- `config.php` содержит реквизиты БД — не публиковать и не коммитить

## Git

Репозиторий локальный, ветка `main`, remote пока нет — история есть только на этом сервере.

- `public_html/config.php` в `.gitignore`. Рядом лежит `config.php.example` с теми же
  полями и пустым `DB_PASS` — при развёртывании копируется и заполняется
- Фотоотчёты `public_html/uploads/tasks/` не коммитятся, каталог держит `.gitkeep`
- Репозиторий принадлежит `claude`, а агент работает под `agent`. Коммитить через
  `sudo -u claude`, обязательно с `umask 002` — иначе новые файлы в `.git`
  потеряют групповую запись и второй пользователь не сможет коммитить
- Выкладка на хостинг по-прежнему копированием файлов, git в ней не участвует
