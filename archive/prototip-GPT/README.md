# Прототип «Служба механиков»

Откройте `index.html` двойным кликом в браузере.

Что уже работает:
- главная диспетчерская;
- 105 единиц техники из файла «Техника.xlsx»;
- поиск и фильтры по парку;
- карточка техники;
- тестовые задачи;
- создание новой задачи в интерфейсе;
- экран загрузки механиков;
- адаптация под телефон.

Важно: это фронтенд-прототип. Созданные задачи хранятся только до обновления страницы.
Для боевой версии на Timeweb потребуется серверная база данных, авторизация и backend.

- карточка каждой задачи;
- обязательный статус + обязательный комментарий механика;
- чат внутри каждой задачи;
- история изменений статусов и комментариев.
