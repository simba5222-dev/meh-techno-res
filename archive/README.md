## Почему здесь нет более свежих версий кода

Между этими архивами и текущим `public_html/` — большая переработка: справочник статусов,
объекты, слесари, доска с перетаскиванием. Сравнивать архивы с текущим кодом построчно
смысла нет, они относятся к предыдущему поколению приложения.
