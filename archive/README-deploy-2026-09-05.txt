СИСТЕМА КОНТРОЛЯ ЗАДАЧ ДЛЯ ОТДЕЛА МЕХАНИЗАЦИИ
================================================

Что это такое
-------------
Веб-сайт, который позволяет главному механику ставить задачи по конкретной
технике линейным механикам, а линейным механикам — принимать задачи в работу
и закрывать их с фотоотчётом. Каждый линейный механик ежедневно подаёт
отчёт о проделанной работе и отмечает, был ли он на работе — это заменяет
бумажное табелирование. Главный механик в любой момент видит дашборд
"кто чем занят", просроченные задачи, табель посещаемости/отчётов ("Табель")
и может сформировать отчёты по механикам, задачам и технике ("Отчёты").
Есть также роль "Менеджер" — только просмотр парка техники, без права
что-либо менять.

Сайт написан на обычном PHP + MySQL, без Node.js, без Docker и без сборки —
подходит для стандартного тарифа хостинга Timeweb (PHP-хостинг).


СОДЕРЖИМОЕ АРХИВА
------------------
schema.sql                  — структура базы данных для НОВОЙ установки.
                              Загружается ОДИН РАЗ через phpMyAdmin. На сайт
                              этот файл заливать не нужно.
migration_manager_reports.sql — миграция для уже РАБОТАЮЩЕГО сайта (если у
                              вас система уже установлена и заведены данные).
                              Добавляет роль "Менеджер" и таблицу ежедневных
                              отчётов/табеля, ничего не удаляя. См. раздел
                              "ОБНОВЛЕНИЕ УЖЕ РАБОТАЮЩЕГО САЙТА" ниже.
seed_equipment.sql          — ваш парк техники (104 единицы), уже занесённый
                              и готовый к импорту. Актуально только для новой
                              установки.
app/                        — сам сайт. Всё содержимое этой папки нужно
                              загрузить в корневую папку вашего сайта на
                              хостинге (обычно public_html или /www).
README.txt                  — эта инструкция.


ОБНОВЛЕНИЕ УЖЕ РАБОТАЮЩЕГО САЙТА
-----------------------------------
Если система уже установлена и работает (пропустите ШАГИ 1-2 ниже — база
уже создана), выполните только это:
1. В phpMyAdmin вашей рабочей базы данных откройте вкладку "SQL".
2. Откройте файл migration_manager_reports.sql из этого архива, скопируйте
   его содержимое целиком и вставьте в поле SQL-запроса, нажмите "Выполнить"/
   "Go". Появится новая таблица daily_reports, а у пользователей станет
   доступна роль "Менеджер". Существующие данные не изменяются и не
   удаляются.
3. Загрузите файлы из папки app/ поверх текущих файлов на хостинге (через
   файловый менеджер Timeweb или FTP) — это добавит новые страницы
   ("Мой отчёт", "Табель", "Отчёты"), обновлённое меню и обновлённый
   дашборд. Файл app/config.php с вашими текущими настройками БД трогать
   не нужно (не перезаписывайте его).


ШАГ 1. Создать базу данных
----------------------------
1. Зайдите в панель управления Timeweb → раздел "Базы данных" (MySQL).
2. Создайте новую базу данных, например: meh_tasks
3. Создайте пользователя базы данных с полным доступом к этой базе
   (или используйте существующего) — запомните логин и пароль.
4. Запишите себе четыре значения: имя базы, хост (обычно localhost),
   логин пользователя БД и его пароль. Они понадобятся в шаге 3.


ШАГ 2. Импортировать структуру базы данных
--------------------------------------------
1. В панели хостинга откройте phpMyAdmin для вашей новой базы данных.
2. Выберите вкладку "Импорт" ("Import").
3. Укажите файл schema.sql из этого архива и нажмите "Выполнить"/"Go".
4. Должны появиться 5 таблиц: users, equipment, tasks, task_history,
   task_photos — и один пользователь admin в таблице users.
5. (Необязательно, но рекомендуется) Повторите Импорт ещё раз, указав
   на этот раз файл seed_equipment.sql — в таблицу equipment добавится
   весь ваш парк техники (104 единицы) с номерами, моделями, ПТС/СТС
   и локацией. Если пропустить этот шаг — начнёте с пустого списка техники
   и внесёте её вручную через раздел "Техника" на сайте.


ШАГ 3. Настроить подключение к базе данных
---------------------------------------------
1. Откройте файл app/config.php любым текстовым редактором.
2. Замените значения на настоящие, полученные в Шаге 1:

     define('DB_NAME', 'ВАША_БАЗА_ДАННЫХ');     -> имя вашей базы
     define('DB_USER', 'ВАШ_ПОЛЬЗОВАТЕЛЬ_БД');  -> логин пользователя БД
     define('DB_PASS', 'ВАШ_ПАРОЛЬ_БД');        -> пароль пользователя БД

   DB_HOST обычно менять не нужно, оставьте 'localhost'.
3. Сохраните файл.

   Кстати: в этом же файле чуть ниже есть две строки —
     define('BRAND_PREFIX', 'Техно');
     define('BRAND_SUFFIX', 'Ресурс');
   Это название, которое показывается в левом меню сайта ("ТехноРесурс").
   Если хотите другое название — поправьте эти две строки.


ШАГ 4. Загрузить сайт на хостинг
-----------------------------------
1. Подключитесь к хостингу по FTP или через файловый менеджер в панели
   Timeweb.
2. Откройте корневую папку сайта (там, где обычно лежит index.php вашего
   домена — например public_html, htdocs или /www/имя_домена).
3. Загрузите ТУДА ВСЁ СОДЕРЖИМОЕ папки app/ (не саму папку app, а файлы
   и папки внутри неё: config.php, index.php, includes/, assets/,
   uploads/ и т.д.) — то есть содержимое app/ должно оказаться прямо в
   корне сайта.

   Если хотите разместить систему на отдельном поддомене (например,
   zadachi.вашсайт.ru) — создайте поддомен в панели Timeweb и загрузите
   содержимое app/ в его папку.


ШАГ 5. Права на папку uploads
--------------------------------
Папка uploads/tasks/ должна быть доступна для записи — туда сохраняются
фотографии, которые механики прикладывают к задачам. Обычно на Timeweb
права выставляются автоматически, но если при загрузке фото возникает
ошибка — через файловый менеджер хостинга выставьте на папку uploads/
права 755 (или 775, если 755 не сработает).


ШАГ 6. Первый вход и смена пароля
------------------------------------
1. Откройте ваш сайт в браузере.
2. Войдите под учётной записью по умолчанию:
     Логин:  admin
     Пароль: admin123
3. НЕМЕДЛЕННО смените этот пароль: раздел "Пользователи" → "Изменить"
   у строки admin → впишите новый пароль в поле "Новый пароль" → Сохранить.
   Не оставляйте пароль admin123 в рабочей системе.


ШАГ 7. Наполнение системы
----------------------------
1. Раздел "Пользователи" — заведите учётную запись для каждого линейного
   механика (роль "Линейный механик") и, если нужно, второго главного
   механика/диспетчера (роль "Главный механик"). Логин механику лучше
   давать латиницей без пробелов, пароль — любой не короче 6 символов
   (потом механик может попросить сменить пароль так же через раздел
   "Пользователи", если у него есть права, либо это делает главный механик
   в user_edit.php).
2. Раздел "Техника" — если вы уже импортировали seed_equipment.sql (Шаг 2,
   пункт 5), весь парк уже на месте — проверьте и при необходимости
   поправьте карточки. Если не импортировали — занесите технику вручную:
   инвентарный номер (обязательно, должен быть уникальным), наименование/
   модель, тип, гос.номер, ПТС, СТС, локацию.
3. Раздел "Задачи" → "Новая задача" — ставьте задачи, выбирая технику,
   исполнителя, приоритет и срок.
4. "Дашборд" — здесь в любой момент видно, кто чем занят, что просрочено
   и какие задачи ждут реакции механика; список техники на ремонте — там же
   ниже.
5. "Табель" — сетка посещаемости и отчётов по каждому линейному механику
   на выбранный месяц (✓ — был на работе, × — не был, пусто — отчёт не
   подан). Здесь же можно вручную добавить/поправить запись за любую дату.
6. "Отчёты" — формирование отчётов по механикам, по задачам и по технике
   за выбранный период, с выгрузкой в CSV (открывается в Excel).


КАК ЭТО РАБОТАЕТ (жизненный цикл задачи)
-------------------------------------------
Новая -> Принята -> В работе -> Выполнена -> Проверена (закрыта)
Главный механик может в любой момент вернуть задачу на доработку
("Возвращена на доработку") с комментарием — механик увидит её у себя
и сможет снова взять в работу. Закрыть задачу (статус "Проверена") может
только главный механик — после того как механик отметил её выполненной
и приложил фото. Вся история изменений и комментарии сохраняются и видны
в карточке задачи.


РОЛИ
-----
Главный механик (admin): видит дашборд, создаёт и назначает задачи,
управляет техникой и пользователями, проверяет и закрывает задачи,
может вернуть задачу на доработку, видит и заполняет "Табель" и "Отчёты".

Линейный механик (mechanic): видит только свои задачи, может принимать
их в работу, менять статус по цепочке и прикладывать фото. Каждый день
подаёт отчёт о работе через раздел "Мой отчёт" (что сделано + был ли на
работе). Может просматривать список техники, но не редактировать её.

Менеджер (manager): видит только раздел "Парк техники" в режиме просмотра —
без права добавлять, редактировать или удалять технику, без доступа к
задачам, табелю, отчётам и пользователям.


ЕСЛИ ЧТО-ТО НЕ РАБОТАЕТ
--------------------------
Белый экран или ошибка 500 — временно откройте app/config.php и поставьте:
    define('APP_DEBUG', true);
Обновите страницу — вы увидите текст ошибки (обычно это неверные данные
БД в config.php). После того как разобрались — ОБЯЗАТЕЛЬНО верните
define('APP_DEBUG', false); — иначе технические детали ошибок будут
видны всем посетителям сайта.

"Не удалось подключиться к базе данных" — проверьте DB_NAME, DB_USER,
DB_PASS в config.php, они должны точно совпадать с данными из панели
Timeweb.

Фото не загружаются — проверьте права доступа на папку uploads/ (см.
Шаг 5), а также что размер файла не превышает 10 МБ.


БЕЗОПАСНОСТЬ
-------------
- Обязательно смените пароль admin после первого входа (Шаг 6).
- Не заливайте schema.sql и seed_equipment.sql на сайт — они не нужны
  на сервере, только для разового импорта через phpMyAdmin.
- Регулярно делайте резервную копию базы данных средствами панели
  хостинга (обычно там есть кнопка "Экспорт backup" или автоматическое
  резервное копирование).
